The app's settings can be set per environment in the Cockpit, under Configuration → Battery Included: the collection and its API key, with a Test button that checks both against Battery Included, the listing sortings, swatch filters and filter fields, and the API address. Values set in the Cockpit reach the module as its options, so nothing changes for a project that sets them in `nuxt.config.ts`.
